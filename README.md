
# Personal Assistant AI 🤖

An AI-powered personal assistant built using n8n and Google Gemini.

## Features

- AI-powered conversations
- Google Search integration
- Gmail integration
- Google Calendar management
- Google Tasks management
- Google Docs notes management
- Expense tracking using Google Sheets
- Conversation memory

## Tech Stack

- n8n – Workflow automation
- Google Gemini – AI model
- SerpApi – Google Search
- Gmail API
- Google Calendar API
- Google Docs API
- Google Sheets API
- Google Tasks API

## Workflow Architecture

Webhook → AI Agent → Gemini + Memory + Tools → Response

## Installation

1. Download the workflow JSON.
2. Open your n8n instance.
3. Select Import from File.
4. Import Personal_Assistant_Workflow.json.
5. Configure your own API keys and Google credentials.
6. Activate the workflow.
